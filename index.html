About / 说明

只读说明 · 非 SettingsConfigurable · 内置行为不可在此开关

只读

SSH ControlMaster

built-in

系统 ssh 使用 ControlMaster=auto + ControlPath=~/.remote-ssh-plus/cm/%C + ControlPersist=10m 复用连接。

ADB 反向转发单独使用 ControlMaster=no（独立连接，避免与其它会话互相拖垮）。

插件内置行为，用户不可在设置页开关。

Mutagen ignore

built-in

创建会话时固定忽略（并 --ignore-vcs），不可编辑 / 不可在 UI 开关：

  • build/
  • .gradle/
  • local.properties
  • .idea/workspace.xml

勿理解为可勾选的「忽略 build/」设置项；签名材料等同理被忽略。

APK 回拉 / 安装

现状

远程 build/ 不同步；成功后由插件阻塞式 ssh cat 回拉到本地同一相对路径。无 Backgroundable Cancel。

本地安装：优先 --fastdeploy（device-side），失败则回退全量 adb install -r。
