Settings / Status strip

连接复用 · mutagen 忽略项 · 路线图

SSH ControlMaster

系统 ssh 使用 ControlMaster=auto + ControlPath=~/.remote-ssh-plus/cm/%C + ControlPersist=10m 复用连接。ADB 反向转发单独使用 ControlMaster=no（独立连接，避免与其它会话互相拖垮）。

Mutagen ignore

默认忽略（并 --ignore-vcs）：

  • build/
  • .gradle/
  • local.properties
  • .idea/workspace.xml

远程构建产生的 APK 在 build/ 内，不同步；成功后由插件 ssh cat 回拉到本地同一相对路径。
