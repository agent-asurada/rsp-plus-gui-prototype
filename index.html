About / 说明

只读说明 · 非 SettingsConfigurable · 不可在此切换内置行为

SSH ControlMaster built-in

系统 ssh 使用 ControlMaster=auto + ControlPath=~/.remote-ssh-plus/cm/%C + ControlPersist=10m 复用连接。ADB 反向转发单独使用 ControlMaster=no（独立连接，避免与其它会话互相拖垮）。

此为插件内置行为，用户不可在设置页开关。

Mutagen ignore built-in

创建会话时固定忽略（并 --ignore-vcs），不可编辑 / 不可在 UI 开关：

  • build/
  • .gradle/
  • local.properties
  • .idea/workspace.xml

远程构建产物在 build/ 内，不同步到本地镜像；成功后由插件阻塞式 ssh cat 回拉到本地同一相对路径。签名材料等同理被忽略，勿理解为可勾选的「忽略 build/」设置项。

Roadmap pending

adb install --incremental：计划在本地安装路径加入按块流式增量安装（需 v4 签名等条件）； 与现有 --fastdeploy → 全量 -r 回退链并存或择优。待实现 · 非当前功能。
